# Career Plan

> 空白模板：把“我以后要做什么”拆成每周能推进一点的小问题。

## 现在能回答的三个问题

1. 我喜欢解决哪一类问题？（和人 / 和数据 / 和创造东西有关）
2. 我目前最拿得出手的一项技能是什么？
3. 未来一年，我最想补齐的一个短板是什么？

## 技能清单

| 方向 | 具体技能 | 状态 |
| --- | --- | --- |
| 专业基础 | 数学、化学课程 | 进行中 |
| 编程 | Python 数据处理 | 入门 |
| 表达 | 写作、演示 | 待练 |
| 英语 | 阅读文献 | 进行中 |

## 时间线

- [ ] 本学期：确定一到两个感兴趣的方向
- [ ] 本学期：完成一个小项目
- [ ] 暑假：实习或科研经历
- [ ] 明年：作品集与个人陈述

> 规划不是一次写完的，每月回来改一次才有用。
